# Research Paper Authoring Rules

## Source of Truth
- Markdown files in `paper/` are authoritative.
- Never modify files in `latex/generated/`; they are regenerated by `make`.
- Preserve the LaTeX template in `latex/main.tex`; change it only for title, authors, keywords, packages, or venue options.
- Follow `STYLE.md` for the publisher's conventions (citation form, reference prefixes, captions, figure widths, front matter).
- Keep each section in its own file under `paper/sections/`, prefixed with a two-digit order number.
- `paper/outline.md` (if present) holds the plan; it is not built into the PDF.

## Drafts
- `drafts/00-raw/` holds raw material (ideas, literature notes, preliminary results). Use it as input; it is not part of the paper and its claims and references are unverified until checked.
- `drafts/NN-label/` (01, 02, ...) are frozen snapshots of the paper at milestones. Never edit them; create new ones with `./build.sh snapshot NN-label`.

## Academic Writing
- Use formal scientific English.
- Do not fabricate references, experimental results, numbers, or quotations.
- Every citation key must exist in `references/references.bib`.
- Mark missing material with `[TODO: ...]` or `[CITATION NEEDED]` instead of inventing it.
- Prefer precise, verifiable claims. Maintain consistent terminology.
- Define each abbreviation at first use.

## Formatting
- Use Pandoc Markdown. Write one sentence per line.
- Cite with brackets only: `[@key]`, `[@a; @b]`, `[@key, p. 5]`. Do not use bare `@key` or prefixes like `[see @key]`.
- Label figures, tables, equations, and sections: `{#fig:name}`, `{#tbl:name}`, `{#eq:name}`, `{#sec:name}`.
- Reference them with `@fig:name`, `@tbl:name`, `@eq:name`, `@sec:name`.
- Use LaTeX syntax for mathematics.
- Image paths are relative to the project root: `figures/name.pdf`. Prefer vector PDF.
- Use raw LaTeX (```` ```{=latex} ```` blocks) only when Markdown is insufficient: two-column figures, complex tables, algorithms. Reference raw-LaTeX labels with the venue's prefix, e.g. `Fig.\ \ref{fig:name}` or `Table\ \ref{tbl:name}`.

## Verification
- Run `./build.sh` after substantive changes; it prints `BUILD OK` with a check summary, or the failing stage and Markdown location.
- Run `./build.sh check` for the full list of unresolved citations, references, and warnings.
- Never modify generated files to fix build errors; fix the Markdown, bibliography, figures, or template.
